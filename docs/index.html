两套能力怎么选

场景推荐能力说明
做内容号 / 客服号，用户在 Sona 里关注并对话公众号消息落在 Sona 的会话里，可视化运营，自带菜单与自动回复
把自己的系统接进来（订单通知、告警、审批）开放平台应用 + 回调应用侧拿到用户授权后，按事件推送；无需用户关注公众号
既要主动推送又要用户在 App 里回复两者组合公众号负责会话，开放平台负责身份与事件

协议速览

  • 鉴权：公众号接口使用登录态（OpenIM 用户 Token），由服务端注入调用者身份；开放平台使用 Authorization: Bearer <access_token> 并叠加 HMAC 请求签名。
  • 请求签名：HMAC-SHA256(secret, "POST\n{path}\n{timestamp}\n{nonce}\n{SHA256hex(body)}")
  • 回调签名：HMAC-SHA256(secret, "HYIM-CALLBACK-V1\n{eventID}\n{timestamp}\n{SHA256hex(body)}")
  • 幂等：所有写接口都带 clientReqID，同值重复提交返回同一结果。
  • 时间窗：签名时间戳允许 -300s ~ +30s，超出即拒绝。
