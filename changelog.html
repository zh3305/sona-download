更新日志

按版本记录新增功能、体验改进与问题修复

v3.8.8 最新 2026-11-22
新增功能
  • 语音转文字：长按 / 右键语音消息即可转成文字，转写结果显示在气泡下方， 支持中英混说；服务端自部署推理，不依赖第三方云服务
  • 聊天文件预览：图片、文件在会话内直接预览，支持下载、保存到本地与打开， 下载进度以圆环显示
  • 全局搜索时间范围：按时间窗口筛选搜索结果，双端一致
体验改进
  • 安装包按 CPU 架构分包：Android 改为 arm64 / armv7 两个独立安装包（63~76 MB）， 客户端自动选择对应版本，不再为用不到的架构付流量（原整包 183.9 MB）
  • 移动端下载升级：APK 改为分片并发下载并支持断点续传，弱网下更稳； 校验失败的分片会被丢弃重下，不会让该版本永久卡死
  • 桌面端更新进度可见：「关于」面板新增检查更新入口，下载中显示实时进度， 下载期间拒绝重复检查
  • 安装包完整性校验改为流式哈希，降低更新时的内存占用
  • 聊天附件缩略图与文件下载链路优化，跨端一致性修复
  • 公众号 H5 菜单在 App 内正常打开（不再因 HTTPS 限制白屏），按来源区分客户端与浏览器
问题修复
  • 修复语音转文字在收起时仍写回结果的竞态
  • 修复 H5 页面切换公众号菜单需重复登录、旧 WebView 存储未清理的问题
  • 修复打包产物启动门禁取错可执行文件名
  • 修复移动端更新清单验签公钥不一致，补齐固定向量回归测试
  • 修复 Windows 检出换行符导致验签夹具损坏、验签误判的问题
  • 堵住出金确认、充值幂等与客户端明文资金请求的安全缺口
v3.8.7 2026-11-19
新增功能
  • 消息收藏：长按消息收藏，在「我的 → 收藏」集中查看；收藏内容独立于聊天记录保存， 删除或清理聊天后仍可回看
  • 合并转发：多选消息合并为一条「聊天记录」卡片转发，接收方可展开查看完整上下文
  • 存储空间管理：按会话统计聊天记录与媒体占用，支持清理缓存、按类型 / 时间范围清理单个会话； 桌面端提供存储空间弹窗与分档清理
  • 全局搜索按类型分栏：搜索结果分「全部 / 图片 / 视频 / 链接 / 文件」查看，支持下钻翻页； 桌面端会话内搜索新增按日期查找
  • 登录安全提醒：新设备登录时向当前账号投递安全提醒，可据此判断是否为本人操作
体验改进
  • 应用内更新：桌面端点更新后静默安装并自动重启（不再弹安装向导）；下载失败会自动切换镜像重试。 移动端改为应用内下载 APK + 直接唤起安装，不再跳转浏览器，启动时可在后台自动下载
  • 公众号内嵌浏览器支持 http 链接（内网 / 测试环境接入方无需证书），凭据与 SSRF 防护保持不变
  • 公众号菜单按渠道正确展示，修复部分菜单点击无响应
  • 过期或已清理的图片 / 文件在聊天中显示明确占位提示，不再长时间空白
问题修复
  • 修复服务重启后全站提示「请先登录」的问题（缓存回源时未注入可信身份）
  • 修复账号已存在时启动期幂等失败导致进程退出的问题
  • 修复钱包卡片防伪造校验从未生效的安全缺陷
  • 修复收藏列表响应体过大与删除后存储不释放的问题
  • 修复删除会话与清空聊天记录的四处缺陷
  • 修复通话信令可被伪造、异常状态滞留的问题
v3.8.6 2026-11-15
新增功能
  • 后台常驻（Android）：登录后以常驻通知保持进程存活，锁屏或切到后台仍能及时收到新消息； 退出登录或划掉任务即停止，不驻留后台
  • 消息接收与后台运行：新增设置页，可查看电池优化、自启动、通知权限状态， 并按手机品牌（小米 / 华为 / OPPO / vivo / 三星等）给出逐步设置指引；首次登录引导一次，7 天内不再重复
  • 公众号消息设置：接收消息、消息免打扰、置顶公众号三个开关，入口在公众号资料页
体验改进
  • 公众号与好友关系彻底解耦：关注后即可直接发消息，不再出现「好友验证」类提示； 通用资料页也能正确识别公众号，只提供关注 / 取消关注，不再显示「添加到通讯录」与「通话」
  • 聊天视频改用系统播放组件，兼容性更好；发送端统一归一化为 H.264，减少对方机型无法播放的情况
  • Windows 自动更新改为版本化下载地址，从本版起后续版本支持差分升级（只下载变化部分，不再每次下整包）
问题修复
  • 修复部分机型打开聊天视频即闪退的问题
  • 修复公众号会话发消息被误报「未添加好友」、消息实际未发出的问题
  • 修复关闭「接收消息」的公众号粉丝仍会收到自动回复与群发的问题
  • 修复通知类账号被当作普通用户添加好友、产生永久待验证申请的问题
v3.8.5 2026-11-15
新增功能
  • 群机器人（Webhook）：群聊可添加机器人，外部系统通过 Webhook 把消息推送到群会话； 支持令牌管理、频率限制、幂等重试与投递审计
  • 星标朋友（桌面端）：好友资料卡可设为星标，通讯录星标分组置顶
  • 朋友圈：滚动时标题栏渐显、双击回到顶部，封面相机入口随滚动收起
  • 朋友权限：新增「不让他看我」「不看他」两个独立开关，覆盖朋友圈与状态
  • 公众号：收敛为单一 IM 会话入口，直接在聊天内交互
体验改进
  • 朋友权限改为底部弹层，补充权限说明文案，小屏可滚动
  • 好友备注资料加载失败时阻断保存，避免空表单覆盖已有标签与描述
  • 构建：.sql 强制 LF，避免 Windows 检出导致 embed 迁移校验失败
问题修复
  • 修复桌面端星标分组遍历全量数据导致的崩溃
  • 修复朋友圈朋友权限弹层在小屏上的溢出与英文文案转义
  • 修复 Webhook 机器人入站解码、令牌校验顺序与重复投递复用等边界问题
v3.8.4 2026-11-14
新增功能
  • 朋友圈：发布图文动态、点赞与评论
  • 聊天外观：可切换聊天主题与聊天背景

  • 聊天拍摄入口：直接拍照 / 录像发送

体验改进

  • 聊天媒体发送展示实时传输进度

  • 表情支持分组，转账消息增加去重

  • 修复更新清单解析（GitHub 资产按纯文本解码后再转 JSON）
  • 修复好友申请通知占用会话列表、通话缺好友门槛
v3.8.3 首个公开版本 2026-11-12
新增功能
  • 会话管理：长按会话可标为已读 / 置顶 / 不显示 / 删除
  • 聊天设置：聊天置顶、消息免打扰、清空聊天记录
  • 消息引用（回复）：长按消息引用，气泡内展示被引用原文
  • 常用表情面板：136 个常用表情，离线内置
  • 消息翻译：多语言互译，译文可收起

  • USDT 钱包：充值、提现、转账、红包、账单、支付密码
  • 语音消息、消息通知
问题修复
  • 修复平台号随机翻转导致的强制登出与登录凭据被清空
  • 修复红包/转账图标使用 emoji 导致的跨端渲染不一致
