更新日志

按版本记录新增功能、体验改进与问题修复

v3.8.4 最新 2026-11-14
新增功能
  • 朋友圈：发布图文动态、点赞与评论
  • 聊天外观：可切换聊天主题与聊天背景
  • 公众号：支持交互菜单消息
  • 设备管理：查看当前在线设备并远程退出
  • 聊天拍摄入口：直接拍照 / 录像发送
  • 桌面端自动更新，移动端改为读取 Release 清单检查版本
  • 新增 macOS 安装包（Apple Silicon 与 Intel 双架构）
体验改进
  • 统一 27 位订单号规范，钱包账单展示更规整
  • 聊天媒体发送展示实时传输进度
  • 转账、红包提交前增加风控前置校验
  • 表情支持分组，转账消息增加去重
  • 下载页新增大陆加速线路（gh-proxy / ghproxy.net / monlor）
问题修复
  • 修复 Android 插件注册文件残留 dev 依赖插件的问题
  • 修复桌面端 after-sign 钩子缺失导致的打包失败
  • 修复更新清单解析（GitHub 资产按纯文本解码后再转 JSON）
  • 修复好友申请通知占用会话列表、通话缺好友门槛
v3.8.3 首个公开版本 2026-11-12
新增功能
  • 会话管理：长按会话可标为已读 / 置顶 / 不显示 / 删除
  • 聊天设置：聊天置顶、消息免打扰、清空聊天记录
  • 消息引用（回复）：长按消息引用，气泡内展示被引用原文
  • 常用表情面板：136 个常用表情，离线内置
  • 消息翻译：多语言互译，译文可收起
  • 语音 / 视频通话 与通话记录（接通时长、未接高亮）
  • USDT 钱包：充值、提现、转账、红包、账单、支付密码
  • 语音消息、消息通知
问题修复
  • 修复平台号随机翻转导致的强制登出与登录凭据被清空
  • 修复红包/转账图标使用 emoji 导致的跨端渲染不一致
