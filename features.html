功能介绍

一个客户端覆盖聊天、通话、朋友圈与 USDT 钱包

即时通讯

  • 单聊 / 群聊，消息多端实时同步

  • 长按会话：标为已读 / 置顶 / 不显示 / 删除
  • 会话置顶、消息免打扰、清空聊天记录

音视频通话

  • 一对一语音 / 视频通话
  • 通话记录：接通时长、未接来电高亮
  • 仅好友可发起通话，减少骚扰
  • 通话中可切换扬声器、静音麦克风

朋友圈

  • 发布图文动态
  • 点赞与评论，实时互动
  • 好友动态聚合浏览

USDT 钱包（TRC20）

  • 充值：专属 TRC20 地址，链上自动入账

  • 转账：会话内直接转账，实时到账
  • 红包：普通红包 / 拼手气红包
  • 账单：流水明细、分类筛选、单据详情
  • 支付密码 + 手势密码双因子保护
  • 收款码 / 扫码支付

账号与安全

  • 好友申请、好友备注、黑名单
  • 设备管理：查看在线设备、远程退出
  • 扫码登录桌面端
  • 全局搜索：联系人、群聊、聊天记录
  • 消息通知：按会话聚合，点击直达

多端与更新

  • Android / Windows / macOS 三端可用
  • 桌面端自动更新，移动端版本检查
